# Public web estate source backups

Snapshot: 5 September 2026.

These archives preserve the complete tracked source and local public assets of the new Quadrant Resourcing, Breaking the Shell, Greebling, and systems-events redirect sites. Each contains BACKUP-MANIFEST.json with SHA-256 hashes and the Sites source commit. Unzip into a clean directory to restore. Keep the existing project ID in .openai/hosting.json when continuing the same Site.

The current live source repositories for RedQuadrant, PSTA, The Necessary Tangle, Resource Optimisation, Antlerboy, and the systems events collector remain their respective repositories under antlerboy. The events collector remains separate; its public interface is integrated at https://transduction.systems/events/.

These backups contain public material only. Private capability notes, strategy, programme records, and credentials are excluded. Ownership and licences remain those recorded in each source project; copying a source archive does not transfer intellectual property or legal-entity ownership. Breaking the Shell remains a separate company and asset owner.

A dated independent OneDrive copy is maintained for this delivery. This snapshot does not itself configure continuous OneDrive synchronisation.
